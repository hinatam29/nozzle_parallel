# kawatani フォルダの案内

静電噴霧による二酸化炭素吸収シミュレーション（川谷さんのコードを元に改良）。
各計算フォルダは独立していて、その中で `make` → `nohup bash run.sh 8 > go.out.log 2>&1 &` で計算できる。
進み具合は、このフォルダで `bash progress.sh`。

## フォルダの分け方

    kawatani/
    ├─ README.md            … このファイル
    ├─ progress.sh          … 計算の進み具合をまとめて表示
    ├─ CHANGES.md           … 1本→並列にしたときの変更履歴
    ├─ docs/                … 説明スライドなど
    ├─ 0_original/          … 川谷さんの元のコード（1本ノズル）
    ├─ 1_single/            … 1本ノズル・円筒（軸対称）
    │   ├─ fieldOLD/        … 電場計算に誤りあり（下記）
    │   └─ fieldFIX/        … 電場計算を修正した版（2026-10-19〜）
    ├─ 2_parallel/          … 並列ノズル（平面2次元・左右が鏡面）
    │   ├─ fieldOLD/        … 電場計算に誤りあり
    │   ├─ fieldFIX/        … 電場計算を修正した版（2026-10-16〜）
    │   ├─ fieldFIX2/       … さらに右のノズル付近の格子のずれを直した版（2026-10-20〜）
    │   └─ fieldFIX3_multi5/ … 液滴を1回に5個並べて出す版＋電場・形・気体の修正（2026-10-22〜）
    └─ 3_opposed/           … 対向ノズル（円筒・同じ軸上で向かい合わせ）
        └─ fieldFIX/

各計算フォルダの名前：`pitch〇〇mm`（ノズル間隔）`_hole〇mm`（対向電極の穴の半幅）`_d〇〇nm`（液滴の平均径）`_k〇〇`（吸収係数 m/s）。
特に書いていない条件は共通：ノズル +7 kV・対向電極 0 V、限界帯電量 100 %、初速度 −3.0 m/s、計算時間 11 ms（55,000 ステップ）。

## 電場計算の誤り（fieldOLD と fieldFIX の違い）

`potential.f` の内部の点の係数で、格子の間隔の代わりに点の座標を使っていた
（`drs = sdx1(i,k)`、`sdx1 = 0.5*(x(i+1)+x(i-1))` は間隔ではなく座標）。
そのため解いている式がラプラス方程式になっていなかった。川谷さんの元のコードから引き継がれていた。
fieldFIX では `drs = 0.5*(x(i+1,k)-x(i-1,k))`、`dzs = 0.5*(y(i,k+1)-y(i,k-1))` に直した。
あわせて、電位は液滴の電荷を含まず毎ステップ同じ答えになるので、最初の1回だけ厳しく収束させて解くようにした（計算時間が短くなる）。

円筒版（1_single/fieldFIX）では、ほかに `potential.f` の 1/r の係数をその点の r(i) に直した（旧: セル境界 r(i+1/2)）。また、電位の解き直しを数回行って十分に収束させる。

リング電極・対向の版では、形を `geo.f` の先頭の「形状の設定」（nopp、xhol、xring、yrc、ytip1、ytip2）だけで決める。geo.f が書き出す `geom.txt` を visualize.py が読んで、ノズルとリングの位置を図に描き、表示する高さの範囲も自動で決める。pout = 5 はノズルに戻った液滴。


## 並列の右のノズル付近の電場（fieldFIX と fieldFIX2 の違い）

`geo.f` の格子幅が `dx = xlen/nx` だったため、電位を解く格子点 i = 1〜nx−1 の右端が x = xlen − 2dx（11 mm で 22 µm×2 手前）になり、右のノズル（x = xlen）が電位の右端からずれていた。そのため右の軸の近くで横向きの電場が正しくなく、右の噴霧だけ細くなっていた。fieldFIX2 では `dx = xlen/(nx−2)` にして、格子点が x = 0〜xlen ちょうどになるようにした（左右の横向きの電場が完全に一致することを確認）。fieldOLD・fieldFIX の並列は、左のノズルの液滴だけで比べる。

## fieldFIX3_multi5（2026-10-22、`tools/patch_v3.py` で fieldFIX2 から作成）

- **液滴の出し方**：1回に 5 個を、ノズルの内径 0.1 mm の幅に横に並べて同時に出す（x = 0, ±0.025, ±0.05 mm、下向き 3 m/s）。出す回数は今まで通り（7 ステップに1回／ノズル）なので、液滴の数（流量）は 5 倍。鏡面（ノズルの軸）を使っているので、計算するのは軸の上の1個と片側の2個の計3個で、反対側の2個は鏡像として入る。液滴番号 k は (k−1) を 6 で割った余りが 0,1,2 なら左のノズル（軸から 0, 0.025, 0.05 mm）、3,4,5 なら右のノズル。**集計するときの重み：軸の上で出た液滴 1、横に出た液滴 2**（`tools/v3stats.py` 参照）
- **液滴どうしの力**：横に出た液滴は自分自身の鏡像の力も入れる（＝軸の反対側に並べた同じノズルの液滴からの反発）。軸の上で出た液滴は1個だけなので入れない。高速化版（`tools/patch_fast.py` と同じ）
- **電場の補間**（`eforce.f`）：距離の逆数の重み → 双一次補間。軸の上では横向きの電場がちょうど 0（旧版は軸の上の液滴にも外向きの電場がかかり、出てすぐ軸から外れていた）
- **電位**（`potential.f`, `ej.f`）：鏡面を格子点の列（x = 0, x = 間隔）にちょうど置く。解き直しを収束するまで繰り返す
- **形**（`geo.f`）：ノズルと電極の端を一番近い格子点に合わせる（ノズル先端 98.8 → 99.0 mm、電極 91.8〜92.6 → 92.0〜93.0 mm）
- **気体**（`diffusion1.f`, `diffusion_gas.f`）：鏡面の列も拡散を計算する。気体の減り方と液滴の吸収量が一致する（旧版は気体の減り方が約 1.5 倍）
- 元のファイルは `*.fix2` として残している

## 1_single/onefactor（2026-10-23〜）：条件を1つずつ変えて比べる（10/22 ゼミの指摘）

川谷さんの条件の再現（`1_single/fieldOLD/repro_7kV`、500 nm・旧電場）から、1つずつ変える。

| フォルダ | repro_7kV から変えたこと |
|---|---|
| `repro_7kV_fieldFIX` | 電場の計算の修正だけ（`potential.f` の係数・1/r・収束、`main.f` で電位を最初に1回だけ解く）。液滴径 500 nm、吸収係数・すべり補正などは川谷さんのまま |
| `repro_7kV_fieldFIX_d11nm` | 上に加えて、液滴径だけを 11 nm（対数正規分布、`rancal.f`）に。すべり補正は川谷さんの式のまま |

- この次の段階が `1_single/fieldFIX/single_7kV_d11nm_k1e-4`（すべり補正の修正、吸収係数 1e-4、飽和濃度・気体の吸収の修正）。液滴の動きに効くのは「すべり補正」だけ（吸収の設定は動きに効かない）
- 途中からの再開（`restart.f`）、kzoku.dat を書かない、高速化（`tools/patch_fast.py`）は物理に関係しない変更として入れている
